# Efsane Taşı Online

Godot 4 ile geliştirilen özgün 3D aksiyon-RPG / MMORPG projesi.

## İlk oynanabilir prototip

- Üçüncü şahıs kamera
- WASD hareket
- Shift ile koşma
- Sol tık ile yakınındaki yaratığa saldırma
- Basit yaratık takip ve saldırı AI'sı
- HP, EXP, seviye ve altın döngüsü
- Test haritası ve üç düşman

## Çalıştırma

1. Godot 4.x'i kurun.
2. Bu repoyu indirin/clone edin.
3. Godot Project Manager'da `project.godot` dosyasını içe aktarın.
4. F6 yerine F5 / Run Project ile çalıştırın.

## Kontroller

- W/A/S/D: Hareket
- Shift: Koş
- Fare: Kamera
- Sol tık: Saldırı
- Esc: Fareyi serbest bırak

## Yol haritası

Sonraki aşamalar: HUD, hedef seçme, loot nesneleri, envanter, ekipman, NPC/görev, yetenekler, geliştirme sistemi, özgün 3D varlıklar ve daha sonra multiplayer sunucu mimarisi.

> Bu proje başka bir oyunun telifli kodunu, hikayesini, haritalarını veya varlıklarını kopyalamaz; türün mekaniklerinden esinlenen özgün bir projedir.
